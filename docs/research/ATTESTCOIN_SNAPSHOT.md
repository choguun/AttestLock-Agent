## Original summary

Attestcoin supplies native verification of facts from registered source chains. Applications still enforce their own business policy after verification. AttestLock uses one proven Sepolia transaction and exact escrow-event validation to open a bounded Creditcoin line. It does not implement source-chain release or default enforcement.

The old snapshot mixed historical tutorial paths and network claims. Implementation authority is the installed, pinned ABI and the current primary references in [ATTESTCOIN.md](../ATTESTCOIN.md), not this archive.
